# DIRESA La Libertad: Juego de Stakeholders

Minijuego 2D de desplazamiento lateral desarrollado en Python con Pygame para el curso
Ingeniería de Software (CIIN1252P, UPN). Recrea el caso de estudio "DIRESA La Libertad"
bajo el enfoque RUP.

El jugador camina hasta la puerta del hospital, presiona E para entrar y recorre las áreas
internas (Admisión, Triaje, Consultorio, Farmacia y Dirección·DIRESA). En cada una conversa
con los stakeholders para conocer su rol y sus necesidades, y observa cómo se resuelven dos
conflictos entre ellos. 

## Controles
- Flechas o A / D (y W / S en pasillos): moverse
- Shift o C: caminar / trotar más rápido (mantén Shift o presiona C para alternar)
- E: entrar al hospital / interactuar / abrir buzón
- TAB: ver u ocultar panel de stakeholders
- F11: pantalla completa
- Esc: salir

## Cómo ejecutarlo
python -m pip install pygame-ce
python main.py
